

Overview
DEVCONF 2026 is a modern, responsive conference landing page and ticketing platform designed for a premier 3-day developer event. It features multi-track scheduling (AI/ML, Cloud & DevOps, Frontend, Security), speaker showcases, pricing tiers, and direct registration pathways aimed at engineers, founders, and tech builders.

Project Screenshot
Main Technologies Used
HTML5 & CSS3 (Structuring and styling the user interface)

JavaScript (Handling dynamic interactions, tabs, and layout behaviors)

Responsive CSS Framework / Custom Flexbox & Grid (Ensuring adaptive design across mobile and desktop viewports)

Main Features
Multi-Track Conference Schedule: Interactive schedule breakdown across 3 days covering tracks like AI/ML, Cloud & DevOps, Frontend, and Security.

Speaker Showcase: Highlight sections detailing headlining speakers (such as Andrej Karpathy, Demis Hassabis, Gary Marcus, and Mustafa Suleyman) along with their roles and tracks.

Tiered Ticketing & Pricing System: Clear tier comparisons (Standard, PRO, and TEAM passes) with structured perk checklists and direct registration actions.

Event Navigation Links: Quick navigation anchors to sections like Speakers, Schedule, Tracks, Venue, and Blog.

Dependencies & Packages
Since this is a static frontend deployment running locally via a live server environment, explicit external runtime package managers (like Node modules) aren't strictly required for viewing, but standard web assets include:

Font/Icon Libraries (Integrated via markup placeholders for UI vectors and branding logos)

Local HTTP Server (e.g., Live Server extension for local testing)

Step-by-Step Guide to Run Locally
Clone or Download the project files into your local directory.

Ensure you have a local development server utility installed (such as the Live Server extension in Visual Studio Code).

Open the project root folder in your code editor.

Open the index.html file.

Right-click and choose "Open with Live Server" (or run a lightweight local server like http-server from your terminal). The app will launch locally at [http://127.0.0.1:5500/index.html](http://127.0.0.1:5500/index.html).
